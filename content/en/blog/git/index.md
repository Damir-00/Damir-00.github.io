## Introduction

Git is a distributed version control system that is widely used in software development.

It allows you to track changes in files, create different versions of a project, return to previous versions and work together with other developers.

## What is version control?

Version control is a system that records changes made to files over time.

The main advantages are:

- tracking changes;
- returning to previous versions;
- creating branches;
- working together with other developers;
- storing the history of a project.

## What is Git?

Git is a version control system created by Linus Torvalds.

Git works locally on a computer, so most operations do not require an Internet connection.

GitHub and other similar services can be used to store Git repositories online.

## Basic Git commands

Some basic Git commands are:

```text
git init
git status
git add
git commit
git log
git branch
git switch
git push
git pull
For example, the following commands can be used to save changes:

git add .
git commit -m "Update project"
git push
Git and GitHub

Git and GitHub are different things.

Git is a version control system, while GitHub is an online platform for storing Git repositories and collaborating on projects.

GitHub allows users to:

store repositories;
work with other developers;
create issues;
review changes;
use GitHub Actions for automation.
Conclusion

Git is an important tool for modern software development.

Learning Git makes it easier to manage projects, track changes and work with source code.

Git is also useful for educational projects because it allows the history of laboratory works and other assignments to be stored.
