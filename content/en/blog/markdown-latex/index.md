## Introduction

Lightweight markup languages are used to format text using simple and understandable symbols.

Two popular examples are Markdown and LaTeX.

They are widely used in programming, education and scientific work.

## What is Markdown?

Markdown is a lightweight markup language designed to make text formatting simple.

For example:

```text
# Heading

## Subheading

**Bold text**

*Italic text*

- First item
- Second item
Markdown is easy to read even without special software.

It is often used for README files, documentation, reports and websites.

What is LaTeX?

LaTeX is a document preparation system that is especially useful for scientific and mathematical documents.

It allows you to create formulas, tables, references and structured documents.

For example, a mathematical formula can be written as:

E = mc^2

A more complex formula can be written using LaTeX syntax:

\[
\int_a^b f(x)\,dx
\]
Markdown and LaTeX together

Markdown and LaTeX can be used together.

Markdown is convenient for writing the main text, headings and lists.

LaTeX is useful for mathematical formulas and scientific notation.

This combination is convenient when preparing laboratory reports and other educational materials.

Advantages

The main advantages of lightweight markup are:

simple syntax;
easy editing;
convenient version control;
good readability;
support for mathematical formulas;
compatibility with many tools.
Conclusion

Markdown and LaTeX are useful tools for creating structured technical and scientific documents.

Markdown makes text formatting simple, while LaTeX provides powerful tools for mathematical formulas and scientific documents.
