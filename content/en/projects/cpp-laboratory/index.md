## About the Project

An academic programming project in C++.

The project implements a program using classes and dynamic memory.

## Main Elements

The program uses the `vect` and `matr` classes.

The `vect` class is designed to work with vectors, while the `matr` class is designed to work with matrices.

The program covers:

- constructors and destructors;
- dynamic memory allocation;
- operator overloading;
- working with vectors;
- working with matrices;
- addition and subtraction operations;
- multiplication;
- object assignment.

## Project Goal

The goal of the project is to gain practical skills in object-oriented programming in C++ and working with dynamic memory.

## Result

As a result, an academic program is created that demonstrates the use of classes in C++ and basic operations with vectors and matrices.
