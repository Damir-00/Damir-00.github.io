## Введение

Git — это распределённая система управления версиями, которая используется для хранения истории изменений в проектах.

Git позволяет разработчику сохранять разные версии файлов, возвращаться к предыдущим изменениям и работать над проектом вместе с другими людьми.

## Что такое система управления версиями

Система управления версиями помогает отслеживать изменения в файлах проекта.

С помощью неё можно:

- сохранять историю изменений;
- возвращаться к предыдущим версиям;
- создавать отдельные ветки разработки;
- объединять изменения;
- работать над проектом совместно с другими разработчиками.

## Основные команды Git

Одними из основных команд Git являются:

```bash
git init
git status
git add .
git commit -m "Описание изменений"
git push
git pull
git clone
```

Команда git init создаёт новый локальный Git-репозиторий.

Команда git status показывает состояние файлов проекта.

Команда git add добавляет изменения в область подготовки.

Команда git commit сохраняет подготовленные изменения в истории репозитория.

Команда git push отправляет локальные изменения в удалённый репозиторий.

Команда git pull получает изменения из удалённого репозитория.

Команда git clone позволяет получить копию существующего репозитория.

## GitHub

Git можно использовать вместе с платформами для хранения репозиториев. Одной из наиболее популярных является GitHub.

В рамках моего учебного проекта GitHub используется для хранения исходного кода персонального сайта и его публикации через GitHub Pages.

## Заключение

Git является важным инструментом современной разработки программного обеспечения.

Изучение Git позволяет лучше организовывать работу с исходным кодом, контролировать изменения и безопасно работать над проектами.
